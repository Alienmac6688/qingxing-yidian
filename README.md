# 清醒一点 V1.6 — 本地优先测试版

打开 `index.html` 使用；部署到 HTTPS 后可安装为 PWA 并启用离线缓存。所有数据默认存储在浏览器 localStorage。

## 已实现
- 保留原始30张卡片与蓝金 ∞ 图标（192/512）。
- 双向训练：初次判断 → 双向分析 → 再次判断及反思，记录前后变化。
- 三种题型的前端交互（选择题、情境题、话术拆解）；题目复用30张卡片，尚未建立完整的独立测验题库。
- FSRS-4.5 **参考实现**，默认权重和90%目标保持率，仅用于记忆复习；不宣称与 Anki 最新 FSRS-6 等价。未优化个人权重，未校准。
- 多标签/领域/题型交叉筛选与关键词搜索。
- 记忆复习与辨识训练统计分离；记录改变观点次数，不把改变视为正确。
- 自建案例（新增、标题与事实编辑、删除）、单案例导出审核草稿；本地修订计数。
- JSON 全量备份/恢复、Anki CSV 导出。

## 未实现
- 账号系统、云端实时同步（仅通过备份文件手动跨设备迁移）。
- 共享案例公开库、审核后台、投稿流程、多人协作与服务端版本管理。
- V1.1旧复习数据自动迁移：旧算法与FSRS状态不兼容，避免假造FSRS复习历史。请保留V1.1备份。
- 标准化的真实生活辨识能力测评；训练数据不等于能力证明。

## 隐私与风险
自建案例不要包含可识别他人的私人信息。JSON备份未加密，请妥善保管。`localStorage` 可能被浏览器清理；使用前定期备份。

## 测试
`node --test tests/*.test.js`。静态文件也可直接本地打开；Service Worker只在HTTP(S)环境注册。
